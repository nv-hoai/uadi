# Static prototype project

This is a dependency-free static web project. It is the clean benchmark snapshot:
both conditions start from a byte-identical copy of this directory.

Deliver the requested experience in this directory:

- `index.html` — the interface
- `styles.css` — styles
- `app.js` — interaction logic
- `analysis.md` — product/UX analysis, decisions, states and unresolved risks

Constraints:

- No network requests, build step, package install or external assets.
- Use semantic HTML and vanilla JavaScript.
