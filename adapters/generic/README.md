# Generic AI agent

UADI can be used by any coding agent that can read project files and follow repository instructions.

1. Make the UADI repository available in the workspace.
2. Ask the agent to read `SKILL.md` and the linked `docs/DESIGN-INTELLIGENCE.md`.
3. Give it a product design, UX review or interface implementation task.
4. Let it use the host's existing tools and project conventions.

A compatible host does not need an authenticated identity provider, signing key, backend, database, MCP server or separate orchestration runtime. Preview and test tools are helpful but optional.

For Codex, Claude Code or Cursor, use the [installer](../README.md) to copy the skill into the native project skill directory.
