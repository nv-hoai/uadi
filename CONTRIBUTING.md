# Contributing to UADI

Thanks for your interest in UADI.

## Current status
UADI is at the early architecture and MVP-foundation stage. Please open an issue to discuss substantial changes to domain models, workflow, schemas, or architecture before submitting a large pull request.

## Principles
- Keep the core agent-agnostic and host-neutral.
- Prefer explicit schemas and examples over ambiguous prose.
- Separate agent recommendations from owner decisions.
- Make artifact changes version-aware and migration-conscious.
- Include validation or compatibility tests for schema and workflow changes.
- Avoid mandatory hosted services in the embedded core.

## Pull requests
Include the problem, decision and alternatives, affected modules/schemas, tests or validation evidence, and migration notes where relevant.
