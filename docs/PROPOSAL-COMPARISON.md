# Proposal Comparison Rubric

Use the same criteria for every direction in one design session. Score each dimension from 1 (weak) to 5 (strong), and attach a short evidence-based explanation. A score is a decision aid, not an automatic selection.

| Dimension | What to assess |
|---|---|
| User-task fit | How directly the direction supports priority tasks |
| Clarity | Information hierarchy, labels, wayfinding, and cognitive load |
| Accessibility | Keyboard, screen reader, contrast, motion, and inclusive interaction |
| Responsive resilience | Behavior across target viewports and input modes |
| Feasibility | Fit with known platform, component, and engineering constraints |
| Consistency | Alignment with approved project patterns and brand constraints |
| Differentiation | Whether the direction offers a genuinely distinct product experience |

## Comparison rules
- Evaluate against the same DiscoveryResult and DesignAnalysis.
- Mark unsupported assumptions; do not disguise missing evidence as a high score.
- Explain material trade-offs and risks alongside scores.
- Do not calculate a winner unless the owner has supplied criterion weights.
- If weights are supplied, show the weighting and arithmetic transparently.
- The owner makes the final selection; the agent does not treat the highest score as approval.
